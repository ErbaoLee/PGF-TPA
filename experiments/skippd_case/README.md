# SKIPP'D 真实预测驱动的光储调度与频率响应实验

本实验复现 2026-10-26 的数值记录。使用 SKIPP'D 2017-09-20 的实测功率，以及本仓已有的 15 分钟视界逐样本预测，比较同一事件下的调度与频率响应。无需图像、GPU、模型重训或外部文件；依赖为 Python 3.12 与 NumPy。

```bash
python -m pip install -r requirements-metrics.txt
# 完整 28 组结果，并与独立保存的数值记录核对
python scripts/run_skippd_case.py --check
# 仅 S1/S2/S3 三个主场景
python scripts/run_skippd_case.py --suite main --check
# 自定义输出目录
python scripts/run_skippd_case.py --output outputs/skippd_run2 --check
python -m unittest discover -s tests -p "test_skippd_case.py"
```

数据与预测文件通过 `reference.json` 中的 SHA-256 校验，预测锚点、输入连续性和 15 分钟目标位移会单独检查。Git LFS 指针文件需要先执行 `git lfs pull`。`--check` 同时核对场景覆盖、指标、触发时间与预爬水平，任一不符将返回非零退出码。

## 输入和时间口径

- 实测：`data/proc/test_meta.npz`；样本索引：`data/proc/test_samples.npz`。
- 预测：`results/preds_TABLE3_{pgf_nocsi_tpa,skybimamba,sunset}_15.npy`，均与完整测试集样本索引对齐。这里的 PGF-TPA 是普通 MSE 的 TPA 三成员集成，不是 TPA-RW。
- 时间为数据原有的 US/Pacific 当地墙钟时间。签发时刻为锚点，目标时刻为锚点加 15 分钟。
- 扫描签发时刻 12:00–15:45，覆盖目标 12:15–16:00。每分钟比较 `实测(签发时刻) - 预测(目标时刻) >= 0.30 × 30.1 = 9.03 kW`。PGF-TPA 首次满足条件为 **12:34**，持续性预测不触发。首警只表示规则满足，不能理解为那一期预测已准确预见 13:58 的陡降。
- 持续性基线取签发时刻实测；3h-MA 只取截至签发时刻的过去三小时实测，不读取未来观测。

## 场景和参数

生产模拟为 12:00–16:00 的 240 个一分钟时段，光伏按 `200 / 30.1` 从 kW 映射为 MW。采用改进 IEEE 30 节点算例的六机参数、200 MW 光伏、30 MW / 120 MWh 储能，初始 SOC 0.55、上下限 0.10/0.90，充放电效率均为 0.95。具体常量保存在脚本顶部。

| 场景组 | 内容 |
|---|---|
| S1 / S2 / S3 | 无储能 / 光储无预警 / 光储加完整干预 |
| S3-charge / preramp / fastctrl / reserve | 分别移除主动充电、预爬坡、快速控制、扩展备用 |
| S2+charge / preramp / ctrl+res | 分别向 S2 加入单项或控制与备用组合 |
| S3@方法 | Sky-BiMamba、SUNSET、持续性和因果 3h-MA 驱动同一规则；不触发时退化为 S2 |
| S3orig-validate | 固定 13:02 触发的历史数值回归检查 |
| PerfectForesight | 真值驱动同一规则的诊断参照，不是经济最优解 |
| tau1/3/5/10 × S1/S2/S3 | 原有滤波实现的 12 组敏感性结果 |

S3 包含主动充电、预爬坡、控制延时调整和备用上限调整。预爬水平采用固定裕度约 22.6744 MW；PGF-TPA 对应 175 MW。快速控制将储能延时由 30 s 改为 0 s，AGC 延时由 30 s 改为 5 s；备用上限由 67 MW 改为 100 MW，仍受当时剩余容量截断。

频率层从 13:58 起算两小时，步长 0.05 s，包含等值惯量、一次调频、AGC、储能功率响应、光伏弃电和三级低频减载。生产模拟切负荷电量与频率层低频减载电量分开报告。

## 实现范围

本入口保留原数值实验的计算口径。预爬时段围绕事后固定的 13:58 事件设置，预爬水平取固定目标时刻的预测；这不是完全在线、仅使用当时可用信息形成的调度策略。结果也同时受到控制延时和备用变化影响，不能全部归因于预测模型。

原滤波系数为 `alpha = 1 / (60 × tau)`，采样步长实际为一分钟。因此 tau=1/3/5/10 对应 Euler 时间常数 **60/180/300/600 分钟**。本入口保留该系数以复现冻结数值，不把标签解释成 1/3/5/10 分钟平滑；敏感性组保持原预测和触发，不重新训练或重新计算预警。

调度层采用带爬坡和功率边界的贪心分配，保留原 SOC 截断更新；频率层为独立等值响应，未耦合储能 SOC 能量约束。它不执行 30 节点网络潮流或 AC 暂态计算。上述结果是该固定事件与参数下的数值复现。
